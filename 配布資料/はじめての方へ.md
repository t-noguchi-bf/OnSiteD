# はじめての方へ　お助けガイド

Salesforceや開発が初めてでも大丈夫です。**作るのはClaude Code**です。皆さんの仕事は、お客様の困りごとを聞いて、Claude Codeに伝えることです。

当日は、チームで1台のPCを全員で使います。自分のPCの準備は要りません。

## 今日やることは3つだけ
1. **お客様に聞く**：何に困っているのか、誰がどこで使うのかを質問する
2. **Claude Codeに頼む**：聞いたことを、そのまま言葉で伝える
3. **画面を見せる**：できた画面をお客様に見せて、感想をもらう

これを3回くり返します（1回25分）。

## お客様への質問のヒント
迷ったら、この順で聞いてみてください。
- 今、いちばん困っていることは何ですか？
- それは、誰が、どこで、どんなときに困りますか？
- 今はどうやって管理していますか？（Excelや紙があれば見せてもらう）
- それができるようになったら、何がうれしいですか？
- いつまでに使えるようになるとよいですか？

聞いた答えは、そのままClaude Codeに伝えて大丈夫です。

## Claude Codeへの頼み方
- 「誰が・どこで・何をしたいか」を伝える。作り方は伝えなくてよい
- 1回に1つずつ頼む
- 最初は早く見せることを優先してもらう。作り込むのは、お客様の反応を見てから

### そのまま使える例文
| 場面 | 例 |
|---|---|
| たたき台を作る | 「店舗のスタッフが、レジ横でお客様の購入履歴をすぐ見られる画面のたたき台を作って。作り込みより、早く見せられることを優先して」 |
| データを入れる | 「`渋谷店_お客様台帳.csv` を取引先として取り込んで。電話番号はハイフンありにそろえて」 |
| お客様の反応を残す | 「お客様から『ほかの店舗で買ったものも見たい』と言われた。Issueにして」 |
| お客様に見せる前 | 「お客様に見せるときの説明メモを作って」 |
| 迷ったとき | 「今どこまでできている？」「次に何をやればいい？」 |
| 失敗したとき | 「さっきの変更を元に戻して」 |

## 出てくる言葉
| 言葉 | 意味 |
|---|---|
| オブジェクト | Salesforceの中の「表」。取引先（お客様の会社や人）、商談、ケース（問い合わせ）など |
| 項目 | 表の「列」。名前、電話番号、購入日など |
| レコード | 表の「行」。お客様1人分、問い合わせ1件分のデータ |
| デプロイ | 作ったものをSalesforceに反映すること。Claude Codeがやる |
| Issue | 「やることメモ」。お客様の要望を1つずつ書いておく場所。Claude Codeが作る |
| コミット・プッシュ | 変更を記録して、チームの共有場所に送ること。Claude Codeがやる |

## 作った画面の確かめ方
1. Salesforceを開き、左上の点が9つ並んだボタン（アプリケーションランチャー）を押す
2. 見たいもの（例：「取引先」）の名前を入れて開く
3. 「新規」を押して、試しに1件入れてみる

どこを見ればよいか分からないときは、Claude Codeに「作った画面はどこで見られる？」と聞いてください。

## 困ったら
- まずClaude Codeに「今どうなっている？」「何がうまくいっていない？」と聞く
- それでも分からなければ、手を挙げて進行役を呼ぶ
- 失敗しても大丈夫です。「さっきの変更を元に戻して」と頼めば戻せます
